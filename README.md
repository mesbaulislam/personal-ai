# 🤖 Personal AI

**Your Personal AI Assistant**

Personal AI is a web-based AI assistant project designed to provide an intuitive and user-friendly experience for interacting with artificial intelligence.

Built with Python, JavaScript, HTML, and CSS, the project focuses on a clean interface, usability, and continuous improvement.

## ✨ Features

- 💬 AI-powered chat interface
- 🖼️ Image interaction and analysis
- 💾 Conversation history
- 🧠 Conversation memory
- 🔐 User authentication
- 🌙 Dark and Light mode
- 📌 Pin and manage conversations
- 🔍 Search conversations
- 📝 Export conversations as TXT
- 📱 Responsive user interface

## 🛠️ Technology Stack

- **Backend:** Python
- **Frontend:** JavaScript, HTML5, CSS3
- **Dependencies:** Python packages listed in `requirements.txt`

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/mesbaulislam/personal-ai.git
```

### 2. Navigate to the Project

```bash
cd personal-ai
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python main.py
```
